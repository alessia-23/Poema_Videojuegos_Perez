# 📜 Proyecto: Plataforma Móvil "Poema"

¡Bienvenido al repositorio de **Poema**, una aplicación móvil interactiva diseñada para la creación, gestión y lectura cómoda de obras líricas y poesías, desarrollada por Alessia de los Ángeles Pérez Palacios.

El objetivo principal de esta aplicación es ofrecer a los usuarios un espacio digital intuitivo que funcione como un **poemario o biblioteca de versos personal**.

---

## 🚀 ¿Qué hace la aplicación? (Funciones Principales)

El sistema permite administrar por completo una colección literaria a través de cuatro funciones básicas (CRUD):

1.  **Escribir Nuevos Poemas (Crear):** Permite al usuario registrar sus propias inspiraciones o poemas de autores favoritos en el sistema, guardando el título y el cuerpo del texto.
2.  **Biblioteca de Lectura (Leer):** Muestra una lista organizada con todas las obras guardadas en el dispositivo para que el usuario pueda seleccionarlas y leerlas.
3.  **Corrección de Versos (Actualizar):** Ofrece la opción de editar cualquier poema almacenado para corregir la ortografía, modificar estrofas o pulir la rima.
4.  **Quitar Poemas (Eliminar):** Permite borrar de manera definitiva una composición de la biblioteca cuando ya no se desee conservar.
